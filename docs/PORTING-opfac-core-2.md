## Behavior added

`CoordinateOperation::requires_per_coordinate_input_time` in `src/iso19111/buildop.rs` is the public form of the existing `Transformation` method. It is true when the method name contains `time dependent` or `time-dependent`, or the method authority is EPSG and the code is 1053 through 1058, or any step of a concatenated operation is. The EPSG:7909 to EPSG:7910 test requires it. The method takes no boolean argument.

## Deliberate differences

C++ compares an accuracy as the strings `6.0`, `1`, `3` and `0`. These tests compare `CoordinateOperation::accuracy()` as `Some(6.0)`, `Some(1.0)`, `Some(3.0)` and `Some(0.0)` metres. The numbers are those values.

`IntermediateCrsUse` is `Allow` or `Never`. PROJ's `ALWAYS` is not a third value. The CH1903 test needs `ALWAYS` to keep a single grid operation; this factory also returns a ballpark, because accuracy 0.2 is not perfect. Ballparks are not dropped globally: the NAD27 to WGS 84 list has 79 operations.
