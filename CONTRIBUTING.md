# Contributing

Contributions are welcome.

1. Fork the repository and create a branch from `main`.
2. Make your change; run `cargo fmt`, `cargo clippy` and `cargo test`.
3. Open a pull request against `main` describing what and why.

All changes go through a pull request reviewed and merged by the maintainer.
Direct pushes, force pushes and branch deletion on `main` are disabled.

For larger changes, open an issue first to discuss the approach.
